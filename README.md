# ARC-HIVE — 연구실 홈페이지

아주대학교 건축학과 건축역사·설계기술 연구실 (Architectural History & Design Technology Lab) 공식 페이지.

- `index.html` 한 파일로 구성된 정적 사이트 (CSS·JS·사진 모두 내장). GitHub Pages로 배포.
- 국문/영문 전환은 페이지 안의 KO/EN 버튼.
- 내용 수정: `index.html`을 직접 고치거나, Claude에게 변경 내용을 말하면 갱신본을 만들어 줍니다.
- 원본 관리 위치: Dropbox `(0) 아주대학교/권용찬 소개 관련/홈페이지/`

## 배포
GitHub 저장소 `<계정>.github.io`의 루트에 `index.html`을 두면 `https://<계정>.github.io/`에서 열립니다.
사용자 도메인을 붙일 때는 저장소 루트에 `CNAME` 파일(도메인 한 줄)을 추가하고 DNS에 GitHub Pages IP를 설정합니다.
